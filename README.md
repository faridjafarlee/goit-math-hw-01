# goit-math-hw-01

Домашнє завдання 1 з курсу Mathematics for Computer Science, GoIT Neoversity: лінійна алгебра в NumPy.

- `task1.py`: контраст, яскравість і змішування зображень як операції з матрицями.
- `task2.py`: косинусна подібність векторів для вибору фільму.
- `task3.py`: визначник і розвʼязок системи лінійних рівнянь.
- `task4.py`: лінійний тренд методом найменших квадратів і прогноз на шостий крок.

## Як запустити

```bash
python -m pip install numpy
python task1.py
```

Так само запускаються `task2.py`, `task3.py` і `task4.py`.
